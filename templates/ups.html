{% else if mode == "none" %}

No UPS found. A UPS keeps the server running through a power cut and shuts it down cleanly if the battery runs low. To add one:

  1. Plug the server (and your router and switch) into the UPS, not into the wall.
  2. Connect the UPS to the server with its USB data cable (the one with a square end).
  3. Reload this page; when it says Detected, run the one command it shows.

Works with USB UPSes that NUT supports (Eaton, APC, CyberPower, Tripp Lite and many more). One that is connected but not listed here can still be set up by hand with NUT.
