Connect your domain

Dockwren publishes each app on its own address, for example blog.yourdomain.com for WordPress or mail.yourdomain.com for a mail client. For that it needs permission to manage the domain you added to Cloudflare. You give it that permission once, with a token, and every app you install later reuses it.

How do I get a token? (about 2 minutes)

Before you start: your domain must already be added to Cloudflare (Cloudflare shows it as Active). A token is like a key card: it only opens what you tick below.

  1. Open dash.cloudflare.com/profile/api-tokens, click Create Token, then Get started next to Create Custom Token.
  2. Name it, for example Dockwren.
  3. Under Permissions add three rows (use + Add more):
    • Account · Cloudflare Tunnel · Edit
    • Zone · DNS · Edit
    • Zone · Zone · Read
  4. Account Resources: Include, your account.
  5. Zone Resources: this decides which domains Dockwren can publish on.
    • Planning several apps on one domain (WordPress, a mail client, a wiki...)? Choose Include, Specific zone and pick that domain. One token then covers all its subdomains, so you never need a new token per app.
    • Use several domains? Add each one, or choose All zones.
  6. Click Continue to summary, then Create Token. Copy the token now: Cloudflare shows it only once.
  7. Paste it above and press Connect. Dockwren lists the domains the token covers. If the one you want is missing, create a new token that includes it and connect again.

You also need a Cloudflare Tunnel that is already connected to this server (Zero Trust, Networks, Tunnels). The tunnel is the secure link that lets visitors reach your apps without opening any port. Never share the token in chats or put it in a repository.
