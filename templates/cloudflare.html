Dockwren checks it with Cloudflare, finds your domains and tunnel by itself, and stores it on this server only (never shown again).

How do I get a token? (about 2 minutes)
  1. Open dash.cloudflare.com/profile/api-tokens and click Create Token, then Create Custom Token (the last option, "Get started").
  2. Name it, for example Dockwren.
  3. Under Permissions add three rows:
    • Account · Cloudflare Tunnel · Edit
    • Zone · DNS · Edit
    • Zone · Zone · Read
  4. Account Resources: Include, your account.
    Zone Resources: Include, Specific zone, then the domain you want to publish on. A token limited to one domain is safest.
  5. Click Continue to summary, then Create Token. Copy the token now: Cloudflare shows it only once.
  6. Paste it above and press Connect.

You also need a Cloudflare Tunnel that is already connected to this server (Zero Trust, Networks, Tunnels). The tunnel is the secure link that lets visitors reach your apps without opening any port. Never share the token in chats or put it in a repository.
