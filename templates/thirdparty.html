Add an app template from a git repository. You give a https URL and one full commit hash; Dockwren fetches exactly that commit, runs the same safety checks as for built-in apps, and shows you the files before anything is stored. Templates that run commands inside containers, or reuse a built-in id, are refused. Nothing updates by itself: a new commit is a new approval. The repository needs manifest.toml and compose.yaml (and optionally icon.svg) at its top level, and this server needs git.
