Compose projects outside the panel

Compose projects running on this server that Dockwren did not create. Adopting one registers it as an app (logs, start/stop, alerts, public hostname) without restarting or recreating anything: its compose file is copied into the panel and must give exactly the same configuration as the running containers. The original files are left untouched. Only projects that pass the same safety checks as a pasted stack and keep their data in named volumes can be adopted. Backups include its named volumes (the stack is stopped for a few seconds while they are copied). Removing an adopted app deletes its volumes.
