Paste a Docker Compose file and Dockwren runs it like any other app: logs, start/stop, backups of ./data, alerts. For safety it must be a self-contained file with ready-made images, ports on 127.0.0.1 and data in named volumes or under ./data. Anything else is refused with the reason.
