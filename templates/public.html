How to create the Cloudflare token
  1. Cloudflare dashboard: profile icon, My Profile, API Tokens, Create Token, Custom token.
  2. Permissions (add three rows): Account / Cloudflare Tunnel / Edit; Zone / DNS / Edit; Zone / Zone / Read. Only for --access: also Account / Access: Apps and Policies / Edit.
  3. Account Resources: Include, your account. Zone Resources: Include, Specific zone, the one domain you publish on.
  4. Create, copy the token once (Cloudflare never shows it again).
  5. Account ID: any zone's Overview page, right column. Tunnel ID: Zero Trust, Networks, Tunnels, open your tunnel (it must be a remotely managed tunnel).
  6. Give the three values to the process that runs dockwren as CLOUDFLARE_API_TOKEN, CLOUDFLARE_ACCOUNT_ID, DOCKWREN_TUNNEL_ID. Never paste the token into a chat or a repository.

Do not put Cloudflare Access in front of apps used by mobile or desktop clients (for example Vaultwarden); the app's own login protects it.
